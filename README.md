
# CRYPTIX

A desktop cryptography workstation built with Python and PySide6 for Hack Club Hack Cast.

## Features

- **Encryption:** AES-256-GCM text encryption and decryption.
- **Hashing:** SHA-256, SHA-512, SHA3-256 and SHA3-512.
- **Password Lab:** Secure password generation.
- **Cipher Lab:** Caesar, Atbash and Vigenère ciphers.
- **Key Vault:** Locally encrypted credential storage.
- **History:** Keeps track of completed operations.

## Technologies

- Python
- PySide6
- Cryptography
- SQLite

## Installation

Clone the repository, then enter its directory.

Create a virtual environment:

```bash
python -m venv .venv
```

Activate it on Linux:

```bash
source .venv/bin/activate
```

Install dependencies:

```bash
pip install PySide6 cryptography
```

Run CRYPTIX:

```bash
python main.py
```
